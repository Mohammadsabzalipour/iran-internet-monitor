اتصال اختیاری Cloudflare Radar

برای دریافت شاخص‌های رسمی Cloudflare API، یک API Token با مجوز Account → Radar → Read بسازید. توکن فقط در همین مرورگر و در حافظه این صفحه استفاده می‌شود و به هیچ سرور واسطه‌ای ارسال نمی‌شود.
راهنمای ساخت توکن
بدون توکن، لینک مستقیم داشبورد Cloudflare در دسترس است اما داده API در این صفحه بارگذاری نمی‌شود.
